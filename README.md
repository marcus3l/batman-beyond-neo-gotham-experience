# Batman Beyond: Neo-Gotham Experience

Uma landing page conceitual e imersiva inspirada no universo de *Batman Beyond*. O projeto apresenta Terry McGinnis, Bruce Wayne, Neo-Gotham e a evolução do traje por meio de narrativa visual, vídeos e interações conduzidas pela rolagem.

## Experiência online

[Abrir a experiência](https://batman-do-futuro-portfolio.marcosj3110.chatgpt.site)

## Destaques

- narrativa cinematográfica controlada pela rolagem;
- transmissões em vídeo com recortes diagonais e sobreposição progressiva;
- sistema visual inspirado em interfaces de vigilância de Neo-Gotham;
- seções responsivas para desktop e dispositivos móveis;
- animações reversíveis ao subir ou descer a página;
- suporte a preferências de movimento reduzido.

## Tecnologias

- React 19 e TypeScript;
- Vinext, Vite e Cloudflare Workers;
- CSS responsivo com animações e transições autorais;
- Intersection Observer e eventos de rolagem otimizados com `requestAnimationFrame`.

## Executar localmente

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```
